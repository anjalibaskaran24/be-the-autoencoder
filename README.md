# 🌸 Be the Autoencoder!
Frontend-only React + Vite game (no backend, no APIs).
## Run
    npm install && npm run dev      # local
    npm run build && npm run preview # production check
## GitHub
    git init && git add . && git commit -m "Be the Autoencoder"
    git branch -M main && git remote add origin https://github.com/<you>/be-the-autoencoder.git && git push -u origin main
## Deploy (Netlify) — app.netlify.com → Add new site → Import from GitHub → build `npm run build`, publish `dist` → Deploy. Copy the https://xxxx.netlify.app URL.
## Deploy (Vercel) — vercel.com → Add New Project → import repo (Vite preset auto-detected) → Deploy.
## Android checklist
Open URL in Chrome · no sideways scroll · tutorial works · R2/R3 locked until passed · fail → retry once · timer pauses on feedback · Sound toggle + beep · win animation only after Round 3 · Share opens share sheet · Restart asks to confirm.
